# AI 智能伴侣 · 使用说明

## 一、这是什么

一个在你自己电脑上运行的 AI 聊天伴侣。不需要注册账号、不上传任何数据，
所有聊天记录都保存在本机，密钥也只存在本机。

## 二、怎么启动

1. 把整个 `AI智能伴侣` 文件夹解压到任意位置（**不要**只把 exe 拖出来，`_internal` 文件夹必须和它在一起）；
2. 双击 **`启动AI智能伴侣.bat`**；
3. 等 10 秒左右，浏览器会自动打开页面（地址通常是 `http://localhost:8501`；
   如果这个端口被别的程序占了，程序会自动换成 8502、8503……，启动窗口里会打印实际地址）。

> 首次启动会稍慢一点（系统要加载依赖），之后通常 3~5 秒。
> 启动失败时程序会在文件夹里留下 `启动日志.txt`，把里面的内容发给作者即可定位问题。

**退出程序**：双击 `停止AI智能伴侣.bat`，或在任务管理器里结束 `AI智能伴侣.exe`。

## 三、第一次使用要填 API Key

程序本身不含密钥，需要你自己申请一个 DeepSeek 的接口密钥（按量计费，很便宜）：

1. 打开 <https://platform.deepseek.com> → 注册/登录 → **API Keys** → 创建；
2. 复制生成的 `sk-` 开头的字符串；
3. 回到伴侣页面，在左侧 **🔑 API 设置** 的输入框里粘贴，按回车；
4. 点一下「🔍 测试连接」，看到绿色的 `连接正常 ✅` 就说明密钥、网络、模型都没问题；
5. 想以后不用每次填，勾选「记住到本机」——密钥会存到程序目录的 `config.json` 里（只在你电脑上）。
   以后不想留了，再取消勾选，文件会被自动删掉。

> 如果「测试连接」提示 `⚠️ 当前模型 xxx 不在可用列表里`，把上面「模型」一栏改成它列出来的名字
> （一般是 `deepseek-chat`）再测一次。

## 四、界面功能

| 位置 | 功能 |
| --- | --- |
| 左侧「新建会话」 | 保存当前对话，开启一段新聊天 |
| 左侧「会话历史」 | 点击会话名切换；点 ✖️ 删除 |
| 左侧「昵称 / 性格」 | 改她的名字和人设，例如「活泼开朗的东北姑娘」 |
| 左侧「🔑 API 设置」 | 填 / 换密钥，测试连接，切换模型，记住到本机 |
| 中间底部输入框 | 输入消息，回车发送；回复会逐字出现 |
| 中间长会话 | 超过 60 条时，更早的消息收进「更早的 N 条消息」折叠区 |

## 五、文件说明

```
AI智能伴侣/
├── AI智能伴侣.exe          # 主程序
├── 启动AI智能伴侣.bat      # 双击启动
├── 停止AI智能伴侣.bat      # 彻底退出
├── 排查问题.bat            # 打不开时双击它，生成「排查结果.txt」
├── 使用说明.md             # 本文件
├── 启动日志.txt            # 启动失败时自动生成
├── config.json             # 勾选「记住密钥」后生成（别发给别人！）
├── sessions/               # 聊天记录，一段会话一个 json
└── _internal/              # 运行依赖，不能删！
```

聊天记录是纯文本 JSON，可以直接打开看，也可以备份/迁移到别的电脑。

## 六、常见问题

**Q1：双击后窗口一闪就没了**
先双击 **`排查问题.bat`**，它会检查文件是否齐全、端口是否被占、程序能否启动，并生成 `排查结果.txt`。
常见的几种原因：
- 只拷了 `AI智能伴侣.exe`，没有 `_internal` 文件夹（最常见）；
- 杀毒软件拦截，或 `_internal` 里的文件被杀毒软件删了；
- 报 `PackageNotFoundError: ... streamlit` —— 这个安装包本身有问题（打包时漏了依赖信息），
  请重新下载最新版本，或改用源码运行。

**Q2：页面打不开 / 一直转圈**
- 先从启动窗口里看它打印的实际地址（端口 8501 被占用时程序会自动换到 8502、8503……）；
- 也可以手动指定端口：命令行执行 `set AI_PARTNER_PORT=8600` 后再启动，然后访问 <http://localhost:8600>；
- 或者重启电脑后再试。

**Q3：提示调用大模型失败**
- 先在左侧「🔑 API 设置」点「🔍 测试连接」，它会直接告诉你错在哪；
- 密钥错了 / 没余额 / 网络需要代理，检查 <https://platform.deepseek.com> 控制台；
- 公司网络可能拦截 `api.deepseek.com`，换个网络试试。

**Q4：怎么备份聊天记录**
复制整个 `sessions` 文件夹即可。

**Q5：杀毒软件报毒**
PyInstaller 打包的程序被误报很常见，属于误报。介意的话可以自行从源码运行
（`pip install -r requirements.txt` 后 `streamlit run app.py`）。

**Q6：能装到手机 / 别的系统吗**
Windows 版只能在 Windows 上跑。想随时随地用，建议部署成在线网页版，见仓库 README 的「部署成在线网页版」。

**Q7：聊得越久越慢、或者突然报「上下文长度超限」**
程序默认每次只把最近 20 条消息发给她（侧边栏底部能看到「上下文：每次带最近 20 条消息」），
所以正常聊多久都不会因为这个报错。想让她记住更多，启动前执行 `set AI_PARTNER_CONTEXT=50`
再启动即可（数字越大越慢越贵，设 `0` 表示完全不截断）。

## 七、这台电脑能开、别人电脑打不开？

先说结论：**九成是传输或杀毒的问题，不是程序本身的问题**。

打包出来的 `_internal` 里已经带了 Python 运行时（`python313.dll`）、
C 运行库（`VCRUNTIME140.dll`、`ucrtbase.dll`）和全部依赖，
所以**不需要别人电脑上装 Python 或任何环境**。

按这个顺序排查：

| 顺序 | 现象 | 原因 | 怎么办 |
| --- | --- | --- | --- |
| 1 | 完全没反应 / 一闪而过 | 只拷了 exe，没带 `_internal` | 整个文件夹一起发，压缩成 zip 再传 |
| 2 | 双击后提示"找不到 xxx.dll" | 同上，或解压不完整 | 重新解压，确认 `_internal` 里有一百多个文件 |
| 3 | 直接双击压缩包里的 exe | Windows 不支持"压缩包内运行" | 必须先解压到硬盘再运行 |
| 4 | `Windows 已保护你的电脑` 蓝框 | SmartScreen 不认识这个新程序 | 点「更多信息」→「仍要运行」 |
| 5 | 文件莫名消失 / 杀毒软件弹窗 | 杀毒软件把 PyInstaller 程序当木马（误报） | 加入信任区；或先关杀毒再解压 |
| 6 | 解压后 exe 变 0 字节 / 损坏 | 微信、QQ 传文件时被压缩或拦截 | 用网盘/邮箱发 zip，别在聊天窗口里直接点开 |
| 7 | 窗口还在，但浏览器打不开页面 | 对方电脑 8501 端口被占 | 已经自动换端口，看启动窗口打印的地址 |
| 8 | 提示 `不支持的 16 位应用程序` / 一堆 DLL 错误 | 对方是 Windows 7/8 老系统 | Python 3.13 只支持 Windows 10 及以上 |

### 让对方发一份诊断文件

让对方双击 **`排查问题.bat`**，会生成 `排查结果.txt`，里面包含：系统版本、文件是否齐全、
端口占用情况、能否启动、以及 `启动日志.txt` 的内容。把这个 txt 发给你，原因基本就写在里面了。

### 最稳的发给别人的方式

1. 用 `压缩` 把整个 `AI智能伴侣` 文件夹压成 zip（别只压 exe）；
2. 通过网盘链接发送，而不是聊天窗口直接拖；
3. 让对方**解压到桌面**再双击 `启动AI智能伴侣.bat`（别放在 `C:\Program Files` 这种没权限的目录）。
